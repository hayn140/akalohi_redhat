image_prep
=========

- A role that cleans/deletes a number of files, logs, dirs and cleans up satellite as well 
- There used to be a seperate mash role but its scope was generic and added to the universal role. 
- Placeholders for both aws and mash exist in case we need them moving forward
- Based in part on this article: https://docs.redhat.c2s.ic.gov/solutions/5793031/
- Using a lot of shell right now, should clean it up at some point...
